## 📱 Objetivo Principal

El objetivo central de esta materia es el **Desarrollo Móvil**. A lo largo de este proyecto (o repositorio) se exploran diferentes enfoques, lenguajes y frameworks para la creación de aplicaciones móviles modernas, escalables y eficientes, abarcando tanto el desarrollo nativo como el multiplataforma, junto con las herramientas de backend necesarias para su funcionamiento.

---

## 🛠️ Tecnologías Utilizadas (Conceptos Clave)

A continuación, se presenta un breve resumen de las principales tecnologías que conforman el ecosistema de desarrollo de esta materia:

### Node.js
Es un entorno de ejecución para JavaScript construido sobre el motor V8 de Chrome. En el desarrollo móvil, Node.js no se ejecuta en el teléfono, sino que es fundamental para construir el backend (como APIs REST o GraphQL que consumen las apps), y para ejecutar herramientas de desarrollo y gestores de paquetes (npm/yarn) que hacen funcionar frameworks como React Native.

### React Native
Es un framework multiplataforma de código abierto creado por Meta. Permite desarrollar aplicaciones móviles para iOS y Android utilizando JavaScript y React. Su mayor ventaja es que no usa vistas web (WebViews), sino que renderiza componentes nativos reales de cada plataforma, ofreciendo un rendimiento muy superior al de las aplicaciones híbridas tradicionales.

### Kotlin
Es un lenguaje de programación moderno, conciso, de tipado estático y totalmente interoperable con Java. Actualmente, es el lenguaje oficial y el estándar recomendado por Google para el **desarrollo nativo en Android**. Permite escribir código más seguro y con menos errores, reduciendo significativamente los fallos comunes como los *NullPointerExceptions*.

### Dart
Es un lenguaje de programación orientado a objetos desarrollado por Google, optimizado específicamente para la creación de interfaces de usuario (UI). Destaca por su capacidad de compilarse tanto *Just-in-Time* (JIT) para recargas rápidas en desarrollo (Hot Reload), como *Ahead-of-Time* (AOT) para lograr un alto rendimiento en producción.

### Flutter
Es un kit de desarrollo de software (SDK) de interfaz de usuario de código abierto, también creado por Google. Utiliza el lenguaje Dart y permite crear aplicaciones compiladas de forma nativa para móvil (iOS, Android), web y escritorio desde **una única base de código**. Flutter dibuja sus propios componentes (Widgets) directamente en la pantalla, lo que garantiza un diseño idéntico en cualquier dispositivo.
